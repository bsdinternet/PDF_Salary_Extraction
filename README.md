# 📊 Salary Slip PDF Extractor

Automated payroll analysis from PagarBook-generated PDF salary slips  

**Python  |  pdfplumber  |  pandas  |  Excel Output**

---

## 📌 What This Project Does

This Python tool automates the extraction and calculation of per-day salary data from salary slip PDFs generated by PagarBook — a popular payroll platform used by Indian SMEs.

Instead of manually reading each PDF and computing deductions, this tool:

- Reads the PDF
- Extracts attendance and earnings data
- Produces a clean Excel report instantly

It currently handles two employees and is designed to work for any PagarBook-format slip, automatically adapting to:

- Date range  
- Employee name  
- Pay rates present in each PDF  

---

## ⚙️ How It Works

### Class 1 — `SalaryMetadataExtractor`

Reads the salary slip's header and summary section using **pdfplumber** to extract:

- **Employee Name** — parsed from `EmployeeName: ...` field  
- **Date Range** — e.g. `26 Dec 25 - 25 Jan 26` (auto-detected, no hardcoding)  
- **Payable Days** — actual working days in the pay period  
- **Earned Basic** — prorated basic pay after absences  
- **OT Amount + OT Hours** — overtime pay and total overtime minutes  
- **Fine Amount + Fine Hours** — late/absence deductions and total fine minutes  

### Calculated Rates

- **Per Day Salary** = Earned Basic ÷ Payable Days  
- **Fine Rate Per Minute** = Total Fine Amount ÷ Total Fine Minutes  
- **OT Rate Per Minute** = Total OT Amount ÷ Total OT Minutes  

---

### Class 2 — `AttendanceExtractor`

Uses `pdfplumber.extract_words()` (with x/y coordinates) to parse the calendar grid.

⚠️ Important Design Note:  
`pdfplumber` collapses all 7 day columns into a single line of text.  
So positional **x-coordinates** are used to correctly map each `P / OT / F` token to its corresponding date column.

For each date in the pay period it captures:

- **P (Present)** — worked hours e.g. `(7:22Hrs)`  
- **OT (Overtime)** — overtime hours e.g. `(2:04Hrs)`  
- **F (Fine)** — late/deduction hours e.g. `(0:46Hrs)`  
- **Status** — Absent / Weekly Off / Paid Holiday  

Then computes:

```
Net Per Day = Base Pay + OT Value − Fine Value
```

## 🐛 Key Bugs Solved

### Bug 1 — Wrong Fine/OT Minutes from Summary Row

Problem:
```
0Mins 19:53Hrs 17:58Hrs
```
Instead of:
```
0 Mins 19:53 Hrs
```

The previous regex only matched space-separated values and mistakenly captured daily attendance times.

Fix:
- Used targeted regex  
- Anchored extraction to the header line containing `OTHours TotalFineHours`

---

### Bug 2 — Calendar Parsing Completely Wrong

Problem:
- `pdfplumber` merges all 7 calendar columns into single lines.
- Original approach searched for date text lines individually.
- Result: massive data loss.

Fix:
- Switched to `extract_words()`
- Used x/y positional mapping
- Assigned tokens to nearest date column dynamically

---

### Bug 3 — OT and Fine Minutes Swapped (No-OT Case)

Problem:
```
0Mins 0Mins 38:12Hrs
```

Extractor incorrectly assigned first non-zero time to OT.

Fix:
- Added safety check:
  - If OT Amount = 0 but OT Minutes > 0 → swap values

## 📦 Installation

### Prerequisites

```bash
pip install pdfplumber pandas openpyxl
```

Note:  
PyMuPDF (`fitz`) is no longer required. The tool now uses only `pdfplumber`.

---

## ▶️ Run the Script

```bash
python working3.py
```

Update `BASE_PATH` in the `__main__` block to point to your PDF file.

Output Excel file is automatically named from the input PDF filename.
